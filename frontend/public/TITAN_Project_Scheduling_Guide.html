TITAN Project Scheduling Guide
Tweet Garot Mechanical · How to set up and manage a project schedule in TITAN
Scheduling Mode
Summary
One start date and one end date for the entire project. All trades and cost types share the same window. Default for all new projects.
Best for: Single-trade jobs, early-stage estimates, or any project where all field work runs one continuous schedule.
Scheduling Mode
Cost Type
Separate date windows per active cost type segment — labor trades (Sheet Metal, Pipefitter, Plumbing) and non-labor types (Material, Subcontracts, Rentals, MEP Equipment, General Conditions). Each segment's forecast is spread across its own window.
Best for: Multi-trade jobs where crews are on-site at different times or the GC schedule breaks out dates by trade.
Scheduling Mode
Phase
Every phase item from Vista drives its own revenue and labor forecast window. Highest precision. Can link directly to GC schedule activities.
Best for: Complex jobs with named phases (mobilization, rough-in, trim-out, commissioning) at different times of year.
▲ Low setup · Enter 2 dates
▲ Medium setup · 1 date range per active cost type segment
▲ High setup · Dates required on every phase
Switching modes is safe.  Change the mode at any time from the Summary tab → Forecast Scheduling Mode selector. Dates saved on the Cost Type or Phase tabs are preserved in the background and restored when you switch back. The Labor Forecast updates immediately — no regeneration step needed.
How to Choose
Mode Use when… Forecast driven by Setup effort
Summary Single trade, lump-sum bid, or project just awarded with no detailed schedule yet Project start date + end date (one window) Low — 2 dates
Cost Type Multiple trades with different on-site windows, or GC schedule shows dates by trade Separate date range per active cost-type segment Medium — 1 range per active cost type segment

Step-by-Step Setup
Mode 1 — Summary Schedule
  1. Open the project → click Schedule in the left navigation.
  2. The page opens on the Summary tab. Confirm the Forecast source badge (top-right) reads Summary. If not, scroll to Forecast Scheduling Mode and select Summary.
  3. Under Project Date Range, click the Start Date field and enter the mobilization date.
  4. Click the End Date field and enter the completion date. Tab out of the field — saves automatically.
  5. Toast confirms: Project dates saved. Labor Forecast updates immediately.
Note: If the project has labor for more than one trade, a yellow banner appears suggesting a switch to Cost Type mode for more accurate forecasting. Dismiss it or click the link to jump to Cost Type.
Mode 2 — Cost Type Schedule
  1. Summary tab → Forecast Scheduling Mode → select Cost Type. The Forecast source badge updates.
  2. Click the Cost Type tab in the tab bar.
  3. The table shows one row per active segment, grouped as Labor (Sheet Metal Field/Shop, Pipefitter Field/Shop, Plumbing Field/Shop, Overhead, BAS) and Non-Labor (Material, Subcontracts, Rentals, MEP Equipment, General Conditions). Only segments with estimated hours or costs in Vista appear.
  4. For each row, click the Start date cell and enter the date that trade begins on-site.
  5. Click the End date cell and enter the finish date. Saves on blur — no Save button.
  6. Optionally set a Contour per row: Flat, Front-loaded, Back-loaded, or Bell curve.
  7. Repeat for every active segment. Headcount updates live.
Tip: If a trade runs the full project span, copy the project start and end dates. Only enter different dates for trades that diverge.
Mode 3 — Phase Schedule
  1. Summary tab → Forecast Scheduling Mode → select Phase.
  2. Click the Phase tab. A green bar confirms: Phase dates are driving the revenue and labor forecast for this project.
  3. Phase codes populate automatically from the Vista contract import — no manual entry needed.
  4. For each phase, click the Start cell and enter the phase start date.
  5. Click the End cell and enter completion. Duration calculates automatically.
  6. Optionally set a Predecessor (row ID of the preceding phase) to model sequential phases.
  7. Optionally set a Contour per phase.
  8. Phases without dates are excluded from the forecast. Enter dates on all phases that carry labor hours.
GC link: Click the GC chip icon on any phase row to link it to an activity on the uploaded GC schedule. Dates sync automatically on re-import.  Provisional phases: Use Add Phase for phase codes not yet in Vista.
Decision Guide
Summary Mode
One window for the whole project
✓
Go — no hesitation: project just awarded, single trade, or early estimate before GC schedule exists
⚠
Upgrade to Cost Type when 2 or more trades appear on the contract with different site windows
✗
Not recommended once the GC schedule has been issued with a phase or milestone breakdown
Cost Type Mode
Per-trade date windows
✓
Go — standard choice: multi-trade job with GC milestone dates available by trade or cost type
⚠
Consider Phase when the job has named phases with meaningfully different crew sizes across the project
✗
Overkill for a single-trade or simple one-phase project — Summary is sufficient
Phase Mode
Per-phase date windows
✓
Go — maximum precision: complex job with detailed GC schedule in hand and phases vary significantly in timing
⚠
Verify coverage: phases without dates are excluded from the forecast — blank dates = missing headcount
✗
Not worth the effort for a small job, single phase, or pre-award estimate
Tips & Quick Reference
Scheduling Principles
  • Always enter an end date — without one the system estimates from contract value and % complete, which is less accurate.
  • Contour shapes affect peak headcount. Flat is the safe default; use Front-loaded or Back-loaded only when you know the crew ramp plan.
  • Start in Summary on award day. Upgrade to Cost Type or Phase once the GC schedule arrives.
  • The Labor Forecast reflects every saved date in real time — no publish step required.
Navigation Quick-Reference
  • Schedule page: Open any project → Schedule (left nav)
  • Mode selector: Summary tab → Forecast Scheduling Mode section
  • Active mode badge: Top-right of the Schedule page — shows current forecast source
  • Labor Forecast: Team Financials → Labor Forecast (real-time)
  • GC Schedule: Project → GC Schedule (upload GC schedule for phase linking)
  • Provisional phases: Phase tab → Add Phase (for codes not yet in Vista)
Set the mode at award, not at handoff.   A firm end date beats a computed one.   Phase mode is only as good as the dates you enter.
